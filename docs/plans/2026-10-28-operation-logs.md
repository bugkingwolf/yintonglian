# 后台操作日志

Go 服务端通过路由包装器自动记录白名单操作，SQLite 新增 operation_logs 表。管理员登录后可通过“操作日志”查看，按起止日期、操作类型、结果筛选，每页50条，时间按浏览器本地时区显示。

记录登录与退出、密码修改、案例及分类客户的维护、公司与团队名片修改、平台配置、素材上传删除和内容导出。记录时间、账号、是否通过身份验证、来源IP、操作类型、对象ID及名称、HTTP状态和结果。删除前保留对象名称，修改公司内容时仅列出受影响成员姓名，不记录电话或微信等字段值。

仅允许已登录管理员查询，无公开接口、编辑或删除日志入口。未通过验证的登录账号单独标识；不读取或保存密码、Cookie、CSRF、完整请求正文、URL查询参数。生产环境仅信任回环代理设置的X-Real-IP，忽略其他来源的转发头；保持部署配置中 Nginx 覆盖 X-Real-IP、Go仅监听127.0.0.1。

日志从部署后开始积累，无法恢复历史；它不是客户浏览统计。当前单一管理员账号无法区分共享该账号的不同人员。日志随完整SQLite备份保存，不包含在内容JSON导出内。日志写入失败会输出服务端错误，不会把已经提交的业务操作误报为失败；当前不自动清理历史日志。

验证覆盖认证、脱敏、发布下架、删除后名称、公司成员修改、分类与客户、分页时间与结果筛选、重开数据库持久化、代理IP防伪、前端转义与分页界面。官网与小程序无改动。
