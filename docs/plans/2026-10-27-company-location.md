# 公司位置与导航

采用后台配置的 GCJ-02 纬度、经度；小程序使用 wx.openLocation 打开固定目的地，官网使用高德地点链接。不调用客户定位接口，不引入第三方地图 SDK 或密钥。

公司原地址：北京市朝阳区北辰汇园大厦G座14层。高德官方地点 B0FFHNM7OF（北辰汇园大厦，北辰东路8号院17号）地图分享的嵌入链接提供纬度39.993970、经度116.403885。坐标对应大厦POI，不代表G座入口或14层。

来源：https://www.amap.com/place/B0FFHNM7OF
核验：2026-10-27，高德地点详情 → 分享 → 嵌入地图，lng=116.403885&lat=39.993970。

新安装默认填写；旧数据仅在原PPT地址未改且经纬度字段均不存在时补齐。保留用户修改后的地址、已有坐标或主动清空的null值。运营可在公司与首页修改或同时清空经纬度以关闭导航。

小程序“关于我们”的公司地址下增加200px原生地图。地图与导航共用后台坐标，仅坐标有效时显示；金色本地标记支持点击显示公司名称及地址。关闭当前位置显示与地图拖动，保留缩放、导航按钮，避免滚动页面时误拖地图。不添加定位权限。

地图交互调整：去掉独立导航按钮，点击地图、标记或标记气泡均调用已有导航入口，打开微信位置详情后选择导航。地图下提示“点击地图查看位置与导航”。
