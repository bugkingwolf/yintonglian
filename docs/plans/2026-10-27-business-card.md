# 电子名片 Implementation Plan

**Goal:** 团队成员拥有可分享的个人名片，运营统一维护个人联系方式与代表案例。

**Architecture:** 扩展现有 Company.TeamMembers JSON 字段，复用公司保存与公开配置 API。公开接口只返回启用成员、已发布案例关联；图片沿用现有上传、引用保护及访问控制。官网 `/people/:id` 与小程序 `pages/member/index?id=` 共享内容。

**Tech Stack:** Go/GORM/SQLite、原生 JavaScript/CSS、微信原生小程序。

1. 扩展成员 phone、wechat、wechatQR、caseIds；验证长度、电话格式、案例引用与图片来源，覆盖媒体删除保护测试。
2. 在公司管理的团队编辑器加入电话、微信、二维码上传、案例勾选及名片链接。沿用成员展示开关。
3. 官网个人名片、代表案例、拨号、复制微信、查看二维码、分享链接和 vCard 下载；保持既有白金视觉。
4. 小程序成员详情、拨号、复制微信、二维码预览、保存联系人及好友分享；无权限或失败提供明确提示。
5. 检查启用/隐藏、缺失联系方式、关联草稿、输入转义、二维码引用；运行 Go 与前端测试并检查页面布局。

第一版不做海报、访问追踪、CRM或自动添加微信好友。保留现有数据，不填造个人电话或二维码。此次只实现和本地验证，不自动 push、部署或上传微信。
